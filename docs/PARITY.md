# Parity between aussiecamps-web and kiwicamping-web

The two sites share one design. A foundation change in one repo is made the same way in the other:
same file names, same exported names, same behaviour. This file lists what is shared and the only
places the two are allowed to differ. The orchestrator diffs the two foundation branches against it.

## Registry decisions both repos make the same way

- Existing locales: hreflang language-only (`["de"]`), `htmlLang` language-only (`de`) except `pt`,
  which is `pt-PT` (the content is European Portuguese; engine variety `pt-PT`). Open Graph as before.
- English: `en-AU` (A) / `en-NZ` (K) for `<html lang>`, hreflang and Open Graph, plus `x-default`.
- Drafts: ja, ko, zh-hans, zh-hant (cjk), da, sv, nb (hreflang `nb` and `no`), cs, pl (latin).
- `reviews`: true for the six original locales, false for every draft. Testimonials are never
  translated into a new language; such a locale need not translate the `review*` keys.

## Redirect stubs (both repos)

GitHub Pages cannot send a 301. A moved or mistyped URL that Search Console shows earning impressions
gets one line in `lib/redirects.ts`, never a hand-written HTML file. The exporter writes the source path
as a static page with `<meta name="robots" content="noindex, follow">`, `<meta http-equiv="refresh"
content="0; url=<to>">`, `<link rel="canonical" href="<SITE_URL><to>">` and a plain link to the target,
in the target's `<html lang>`. A stub is never in a sitemap or an hreflang set. The export fails when a
source is also a real page or a target is not one; `audit-seo` checks every stub; a test checks the
markup and sitemap absence.

## Allowed divergences

| Area | AussieCamps | KiwiCamping |
|---|---|---|
| Site constants | `SITE_URL`, `APP_ID` 6801098680, brand "AussieCamps", AUD | campingapp.nz, 6746952595, "KiwiCamping", NZD |
| Country-wide region in `lib/related.ts` (`COUNTRY_REGION`) | "Australia" | "New Zealand" |
| Article storage | `lib/site.ts` + `lib/expanded-articles.ts` + `lib/article-faqs.ts` | `lib/content/*` |
| Rendering for export | the built worker (`dist/server/index.js`, vinext + Cloudflare plugin) | its own build output |
| URL freezes | `docs/growth/ranking-urls.txt` (clicks or 20+ impressions) and `docs/growth/url-baseline.txt` | the same two files (ranking list from Search Console 2026-10-19, including the 15 legacy `.html` pages), plus `rankingUrls` in `audit-content` |
| Legacy body check | none | `scripts/verify-legacy-bodies.mjs <origin/main pages-dist>`: one-off for foundation changes, not in `check` (content work rewrites legacy pages) |
| Stamp leaf keys | `leaves()` returns an array | `leaves()` returns a Map and uses the engine's JSON-pointer form for unusual keys; same keys for every current file |
| Section tables in guides | `sections[].table`, gated by `isArticleComplete` | none |
| Legacy pages | none | `/<legacy>.html` in English, `/<seg>/guides/<slug>/` translations, in `alternatesFor` |
| Route kinds from feature threads | `tool`, `hub` (`/camping/`, `/dump-points/`, `/rest-areas/`) | `tool`, `hub` (`/camping/`, `/huts/`, `/freedom-camping/`, `/dump-stations/`) |
| Analytics module shape | `lib/analytics.ts` exports `analyticsBootstrap` and `consentRegions`; consent bar in `components/analytics.tsx`; stored choice key `ac_consent` | `lib/analytics.ts` exports `analyticsScript`, `CONSENT_REGIONS`, `CONSENT_TIME_ZONES` and `COOKIE_EXPIRES_SECONDS`; consent bar in `components/consent-bar.tsx`; stored choice key `analytics-consent`. Behaviour must still match: consent regions, consent-bar time zones (Europe plus Canary, Madeira, Azores, Reykjavik, Cyprus, Ceuta and the French outermost regions), 13-month cookies, page labels on every event. Never rename either storage key: every visitor who already chose would be asked again. |
| Drip publishing (`lib/publish.ts`) | `publishAt` on articles in `lib/site.ts` and `lib/expanded-articles.ts`; `Article` type in `lib/site.ts` | `publishAt` on `makeArticle` inputs in `lib/content/*.ts`; `Article` type in `lib/article-model.ts`; a legacy `.html` guide may not carry one (always published) |
| Product name in parity checks | "AussieCamps" | "KiwiCamping" |
